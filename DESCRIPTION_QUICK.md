## 🌀 One-Liner
**An agentic loop that thinks, acts, observes, reflects, and learns—making AI smarter with every task.**

---

## 📝 Quick Descriptions

### For the Impatient (20 words)
Self-learning AI agent. Executes tasks. Learns from results. Gets smarter over time. Production-ready.

### For Builders (50 words)
Spiral is a production-ready framework for building self-learning AI agents. Built with LangGraph, Mem0, and Claude—it executes multi-step tasks, learns from every execution, and improves over time. Beautiful React UI shows everything in real-time.

### For Technical People (100 words)
Spiral implements a 7-node agentic loop: Analyzer → Memory Retriever → Planner → Executor → Observer → Reflection → Learning. Each node is a Claude API call with structured reasoning. Tasks are executed against real tools (file ops, Python, web search). Results are observed and reflected on. Learnings are persisted to Mem0. Next time around, relevant memories are retrieved to inform better decisions. The loop repeats indefinitely, with exponential learning.
